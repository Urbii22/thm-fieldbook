# Sistema personal de estudio

Esta carpeta convierte el curso existente en una asignatura práctica de 16 semanas. No sustituye los módulos: decide cuándo leerlos, qué practicar, cuándo pedir ayuda y cómo medir autonomía.

## Empezar ahora

1. Abre [Semana 1](semana_01.md).
2. Copia la [plantilla de sesión](plantilla_sesion.md) en tus notas.
3. Consulta el [sistema de pistas](sistema_de_pistas.md) solo cuando se cumpla el tiempo indicado.
4. Registra el laboratorio en el [registro de autonomía](registro_de_autonomia.md).
5. Si hubo bloqueo, completa el [diario de bloqueos](diario_de_bloqueos.md).

## Regla de uso

Cinco sesiones semanales de 90-120 minutos. La semana se completa por evidencia de razonamiento y práctica, no por haber leído todo ni por terminar una máquina.
