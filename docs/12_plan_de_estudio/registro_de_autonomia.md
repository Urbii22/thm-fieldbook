# Registro de autonomía

Terminar una máquina no basta. La métrica principal es cuánta ayuda fue necesaria para formular y validar decisiones.

## Escala A-G

| Nivel | Ayuda máxima utilizada | Interpretación |
|---|---|---|
| A | Ninguna | Resuelto con hipótesis, controles y evidencia propios |
| B | Solo documentación oficial | Autonomía práctica con investigación primaria |
| C | Pista conceptual | Necesitó dirección, construyó técnica y prueba |
| D | Pista sobre la técnica/primitiva | Reconoció cómo aplicarla después de nombrarla |
| E | Pista sobre el payload | Adaptó una estructura parcialmente revelada |
| F | Solución parcial | Completó pasos a partir de una secuencia ajena |
| G | Write-up completo | Reprodujo una resolución completa |

La trayectoria deseada es `G → F → E → D → C → B → A`. Un nivel aislado no define progreso; usa una media móvil de los últimos cinco laboratorios y compara tareas del mismo tipo.

## Indicadores útiles

- **Autonomía:** porcentaje de laboratorios en A-C.
- **Disciplina experimental:** porcentaje con baseline, hipótesis y control negativo.
- **Dependencia fuerte:** porcentaje en F-G.
- **Latencia de ayuda:** minutos de trabajo útil antes de pedirla, sin premiar atasco improductivo.
- **Transferencia:** porcentaje de casos D21 resueltos en nivel igual o mejor que el original.

## Regla de progreso

Considera mejora cuando, durante tres semanas, aumenten A-C o disminuyan F-G sin caer la calidad de evidencia. Si terminas más laboratorios pero sube F-G, reduce cantidad y repite casos de adaptación.
