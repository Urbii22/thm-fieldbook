# Examen de fundamentos

Duración: 90 minutos. Sin solucionario durante el intento.

1. Descompón una URL con esquema, autoridad, puerto, path, query y fragmento.
2. Distingue cookie, sesión, autenticación y autorización.
3. Interpreta `Content-Type: application/json` con un cuerpo de formulario y predice la capa del error.
4. Explica encoding, canonicalización y cifrado con un ejemplo de cada uno.
5. Diferencia shell, proceso, binario, biblioteca, parser e intérprete.
6. Predice el orden de expansión, splitting y redirección en una línea Bash sencilla.
7. Modela source, transformación, validación y sink en una consulta SQL concatenada.
8. Construye una prueba mínima verdadera/falsa sin extraer datos.
9. Propón mitigación para validación textual de una URL destinada a petición servidor.
10. Escenario: una API recibe query, cookie y JSON. Dibuja todos los parsers y diseña cuatro controles que cambien una sola entrada.
